Supabase Backend Configuration

The Supabase JS client is installed in your workspace. You can connect your live Supabase cloud database by configuring .env.local.

# .env.local NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key

Supabase SQL Schema:

CREATE TABLE inquiries ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, name TEXT NOT NULL, email TEXT NOT NULL, message TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW() );
